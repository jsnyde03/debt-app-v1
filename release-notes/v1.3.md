# v1.3 Release Notes

## App Store "What's New" copy

iPad support is here. The app now runs natively on iPad with a layout designed for the larger screen.

- Sidebar navigation replaces the bottom tab bar on iPad
- Bills section shows Expenses and Debts side by side in portrait
- Goals and Payoff tabs use a two-column layout in landscape
- Modals and the Settings sheet open as centered panels instead of bottom sheets
- Added "Delete All Data" option in Settings for a clean reset

Also fixed: several minor layout issues on iPhone.

This release adds App Lock — secure the app with Face ID, Touch ID, or your device
passcode, free for everyone, off by default. Premium subscribers also get local

NEW FEATURES

App Lock (Free, all tiers)
  Secure Paycheck Debt Planner with Face ID, Touch ID, or your device passcode. A
  toggle in Plan Settings, off by default — turn it on whenever you're ready.
  Authentication happens entirely through Apple's on-device Face ID/Touch ID system;
  Debt Planner never receives, stores, or has access to any biometric data, only a
  yes/no confirmation that you unlocked successfully. If your device has no biometric
  or passcode security set up at all, the app won't lock you out with no way back in.

Try with Sample Data (Free, all tiers)
  New users can now explore the full app populated with realistic sample bills, debts,
  and goals before entering their own numbers — no manual setup required to see what
  the app does. A persistent "Demo Mode" indicator makes it clear you're viewing sample
  data, with a one-tap "Start My Own Plan" action to clear it and begin fresh whenever
  you're ready. Sample data never affects your real subscription status.

Local Notifications (Premium)
  Two reminders, both opt-in and capped at one per moment so they stay useful, not noisy:
    - Paycheck-eve reminder the evening before your next payday, so you remember to run
      your plan the moment money lands.
    - Upcoming bill alert a couple of days before your earliest unpaid bill is due, only
      when there's something that actually needs attention.
  Notifications reschedule automatically every time you calculate a plan or roll over to
  the next pay cycle, and turn off cleanly if you revoke notification permission at the OS
  level.

App Store Review Prompt
  After completing a few pay cycles, Paycheck Debt Planner may ask if you'd like to leave a
  review. This uses Apple's native in-app review prompt — it only ever asks once, and how
  (or whether) it appears is entirely controlled by Apple, not by us.

VISUAL REFRESH

  Replaced emoji-based icons throughout the bottom navigation, settings, and section
  switchers with a consistent icon set for a more polished, native feel.

  Redesigned the Notifications and App Lock toggles as proper sliding switches, matching
  the style you'd expect from any iOS settings screen.

  Added haptic feedback across tab switches, primary buttons, and previously-silent
  interactions, so the app responds consistently to touch throughout.

  Increased touch-target sizes on a couple of smaller controls to meet Apple's accessibility
  guidelines, and improved keyboard handling on the paycheck amount field.

EASIER SUBSCRIPTION MANAGEMENT

  Added direct links to manage your subscription and view Terms of Use from both Plan
  Settings and the upgrade screen, alongside the existing Privacy Policy and Support links.

  Fixed an issue where the Premium upgrade screen could be difficult to find for users who
  hadn't yet added a debt — it's now reachable directly from the Payoff tab regardless of
  how much data you've entered.

STABILITY AND ENGINE

  Fixed a bug where the 3-month cash-flow forecast's "recovery month" was calculated but
  never actually shown to users when cash was projected to recover within the forecast
  window — it's now displayed correctly on every month leading up to recovery.

  Fixed a gap in premium feature-gating logic for Smart Insights that fell through to the
  correct default but was missing its explicit case — now handled directly.

  Fixed App Lock defaulting to enabled for new installs, which could block first-time setup
  entirely on devices without biometrics configured — now off by default, opt-in from Plan
  Settings.

  Several regression tests were quietly failing because they expected an older, since-changed
  rule (unconfirmed snowball/emergency payments showing in the timeline by default). Rewrote
  them to test the actual current behavior — only payments you've explicitly marked complete
  appear in the timeline.

  Expanded end-to-end test coverage across paycheck setup, debts, expenses, goals, dark mode,
  the full pay-cycle rollover flow, and the new demo-mode path.

KNOWN CONSTRAINTS

  App Lock's native authentication prompt can't be meaningfully automated in our test suite
  (it's a real OS-level Face ID/Touch ID dialog) — verified manually on-device instead.

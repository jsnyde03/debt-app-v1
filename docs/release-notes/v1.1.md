Paycheck Debt Planner — V1.1 Release Notes

New Features

Autopay Support
Added autopay tracking for expenses and debts
Autopay items are visually identified throughout the app
Autopay allocations now appear separately in planning flow
Added autopay support to timeline view
Editable Recommendations
Recommended savings and snowball amounts can now be edited
Added recommendation override system
User-adjusted recommendation amounts now persist correctly during the session
Timeline View
Added chronological paycheck timeline

Timeline displays:

paycheck received
expenses
debt minimums
autopay items
emergency fund contributions
snowball payments
Added running safe cash display throughout timeline
Flexible Cash Accuracy Improvements
Fixed issue where outside payments incorrectly increased flexible cash
Added distinction between paycheck-funded and externally-funded payments
Added “Paid Outside Paycheck” workflow for recommendations

UX Improvements

Added autopay badges throughout the UI
Improved organization of recommended actions
Improved mobile readability
Improved planning visibility for upcoming obligations

Stability & Engine Improvements

Added timeline regression coverage
Added autopay regression coverage

Improved isolation between engine state and UI override state

Internal Improvements

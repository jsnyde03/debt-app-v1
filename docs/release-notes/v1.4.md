## App Store "What's New" copy

A guided setup now walks new users through their first plan in under two minutes — no blank-screen confusion.

**Timeline improvements**
- Bills that were silently missing from the timeline now appear correctly — the view projects up to 3 pay cycles forward so nothing gets dropped
- Your cash buffer reserve is now visible as a line item, so the ending balance matches what you actually have
- Bills due on the same day as your paycheck now appear in the timeline correctly instead of being skipped
- Dollar amounts stay visible even when multiple status badges (category, autopay, paid) appear on the same row
- Long cycles with many line items no longer get cut off mid-list

**Plan summary**
- Your projected debt-free date now appears directly in the plan summary strip, updated every time you run a plan

**Payoff visualization**
- A trajectory chart in the Payoff tab plots your balance over time for both Snowball and Avalanche strategies so you can see at a glance how fast debt drops
- A 3-month cash flow health bar at the top of the Forecast section gives you an instant status read — green for stable, amber for tight, orange for pressure, red for critical
- Each debt card now shows a progress bar when you've paid down from the original balance, so every payment feels like visible progress

**Swipe-to-delete undo**
- Accidentally swiped away a debt or bill? A 5-second undo toast lets you bring it back before it's gone

**Appearance**
- Theme selector in Settings: choose Auto (follows your device), Light, or Dark

**Polish throughout**
- Animated checkmark when you mark a debt or bill paid
- Interest cost shown on each debt card so you can see what inaction costs per month
- Empty sections now show an icon so the screen doesn't look broken
- Animations when switching tabs and when lists load
- Delete All Data in Settings is now a clearly-labeled button, not a hidden text link
- Fixed a rendering glitch on iOS where buttons showed a dark background on tap

## Full scope (internal)

### Timeline fix (highest-impact bug fix in this release)
- `buildMultiCycleTimeline` — new, projects up to 3 pay cycles forward
- `buildTimelineItems` — emits a `"buffer"` type item so cash buffer is visible
- Multi-cycle accordion UI: current cycle expanded by default, future cycles collapsed with date-range header and color-coded ending balance chip
- 3 regression tests added for buffer item behavior

### Onboarding flow (new users)
- 4-step guided setup: Welcome → Paycheck → First Debt or Bill → Completion
- Demo Mode ("Try with Sample Data") moved to Welcome screen as a secondary CTA
- `useOnboarding` hook + `hasCompletedOnboarding` localStorage flag; existing users with a paycheck set skip the flow automatically
- Gate condition: `!hasCompletedOnboarding && !isDemoMode`
- E2E Playwright spec: 5 tests, 20 runs across 4 device profiles — all green

### UX polish (22 items)
- `#2` First-launch empty state card (Plan tab, no debts)
- `#3` Debt-free date in execution summary strip
- `#4` Mark-paid animation: `checkPulse` overlay + `cardExit` dim
- `#5` Smart Insights card typography: larger title, severity left-border, chip styling
- `#7` Debt type icons: CreditCard chip / BNPL badge
- `#8` Plan tab hero subtitle: contextual (shortfall / debt-free date / default)
- `#9` Display amount styling: superscript `$` symbol and cents
- `#10` Directional tab transitions: slides left/right based on tab order
- `#11` Upgrade screen preview card: blurred mock insights with frosted overlay
- `#12` Windfall/Bonus allocator in Plan Settings
- `#14` BNPL visual differentiation: purple badge, "X payments left" replaces APR
- `#17` Aria-label audit: hero, navs, tab region, execution strip
- `#20` Swipe-delete undo toast (5-second window)
- `#22` Sheet grabber handles on Settings and Upgrade sheets
- `#23` Toast animation: slide-up enter, fade exit
- `#24` Staggered list entrance animations
- `#25` Monthly interest cost callout per debt card
- `#26` Haptic grammar: error haptic on validation, medium on successful imports, swipe-delete upgraded to medium
- `#27` 3-way theme selector (Auto / Light / Dark) in Settings; floating toggle removed
- `#28` Privacy note in Settings: "Your data stays on this device"
- `P4` Empty-state icons: 48px Lucide icons in Debts, Bills, and Goals
- `P9c` Hover → active CSS audit: touch targets now respond on tap across all interactive elements

### Payoff visualization (3 new features)
- `#1a` **Payoff Trajectory Chart** — `SnowballSection.tsx`: SVG chart in `payoff-summary-col` plotting total balance over time for both snowball (blue) and avalanche (purple) strategies. Powered by new `lib/debt/buildPayoffTrajectory.ts` which runs the same month-by-month simulation as `projectDebtPayoff` but captures total balance each month (capped at 120 months).
- `#1b` **3-Month Cash Flow Status Bars** — inside the Forecast card: a compact 3-column bar strip above the existing forecast cards. Bar width = `min(100%, safeCash / $400)`, color by `ForecastStatus` (stable/tight/pressure/recovery → green/amber/orange/red).
- `#1c` **Per-Debt Progress Bars** — `DebtRow.tsx`: thin 5px track inside each debt card, below the interest callout. Only shown when `debt.originalBalance` is set and `displayBalance < originalBalance` (some progress made). CSS gradient blue bar, 500ms transition.

### Settings — Delete All Data
- Restyle from bare text link to full-width outlined danger button with red-tinted danger zone container
- Confirmation warning reworded to lead with what gets deleted

## App Review Notes (paste into App Store Connect → Version Information → Review Notes)

```
New in v1.4: a 4-step onboarding flow for first-time users and several timeline bug fixes.

HOW TO SEE ONBOARDING:
The onboarding flow runs once per install. To trigger it during review, delete and reinstall the app (or clear the app's local storage in Safari dev tools). Existing users who already have a paycheck set bypass onboarding automatically and land directly in the main app.

DEMO MODE:
On the Welcome screen, tap "Try Sample Data" to explore the app with pre-populated debts and bills — no setup required. A yellow "Demo Mode" banner appears throughout; tap "Exit Demo" to return to a blank slate.

IN-APP PURCHASES:
All IAP access points remain the same as v1.2/v1.3:
• Tap "Upgrade to Premium" in Settings (gear icon, bottom-right of any tab)
• Tap any locked feature on the Insights tab: Smart Insights, Strategy Comparison, What-If Simulation, or 3-Month Forecast
Use a Sandbox Apple ID to complete a test purchase without being charged.

No account or login is required. All user data is stored locally on the device.
```

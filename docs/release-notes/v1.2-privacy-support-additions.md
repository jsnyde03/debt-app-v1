## Privacy Policy — new section

Add this as its own section, consistent with the existing point-based style. Suggested
placement: right after the existing "Key Points" / data-collection section, before the
RevenueCat/analytics section.

```
**App Lock (Face ID / Touch ID)**

Paycheck Debt Planner offers an optional App Lock feature, off by default, that secures
the app using Face ID, Touch ID, or your device passcode. Authentication is handled
entirely by Apple's on-device Face ID/Touch ID system — "Debt Planner never receives,
stores, or has access to your fingerprint, face data, or any biometric information."
The app only receives a yes-or-no confirmation that you authenticated successfully.

App Lock can be turned on or off at any time in Plan Settings. If your device has no
biometric authentication or passcode configured at all, App Lock will not prevent you
from accessing your own data.

**Try with Sample Data**

Paycheck Debt Planner offers an optional "Try with Sample Data" feature on first launch
that populates the app with realistic example bills, debts, and goals, so you can explore
how the app works before entering your own financial information. Sample data is stored
only on your device, exactly like your own data would be, and can be cleared at any time
via "Start My Own Plan." Using sample data does not create an account or send any
information off your device.
```

## Support Page — new section

The current support page has no FAQ section. Suggested addition right before the
"IMPORTANT DISCLAIMER" line:

```
App Lock

If you've turned on App Lock and are having trouble unlocking the app:
- Confirm Face ID or Touch ID is enabled for Paycheck Debt Planner in your device's
  Settings app, under Face ID & Passcode (or Touch ID & Passcode).
- If biometric authentication isn't available, you can always unlock with your device
  passcode instead.
- App Lock can be turned off at any time from Plan Settings once you're unlocked.
- If you can unlock your phone at all, you can unlock the app the same way — App Lock
  relies entirely on your device's own security, not a separate password.

Try with Sample Data

- On first launch, tap "Try with Sample Data" to explore the app with realistic example
  bills, debts, and goals already filled in.
- A "Demo Mode" banner stays visible at the top of the app the whole time you're viewing
  sample data, so it's always clear it isn't your real information.
- Tap "Start My Own Plan" from that banner at any time to clear the sample data and start
  fresh with your own numbers — this can't be undone, so make sure you're ready before
  tapping it.
- Sample data doesn't unlock Premium features — you'll see the same upgrade screen you
  would with your own data.
```

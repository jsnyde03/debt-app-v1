# v1.3 Release Notes

## App Store "What's New" copy

iPad support is here. The app now runs natively on iPad with a layout designed for the larger screen.

- Sidebar navigation replaces the bottom tab bar on iPad
- Bills section shows Expenses and Debts side by side in portrait
- Goals and Payoff tabs use a two-column layout in landscape
- Modals and the Settings sheet open as centered panels instead of bottom sheets
- Added "Delete All Data" option in Settings for a clean reset

Also new: the app now respects your iPhone or iPad's system Dark Mode setting on first launch — no manual toggle needed. Plus polish across currency inputs, haptic feedback, and visual refinements throughout.

---

## Full scope (internal)

### iPad native layout
- Universal binary (UIDeviceFamily 1,2)
- Sidebar nav at 834px+, bottom nav hidden on iPad
- Two-column Bills (Expenses + Debts side-by-side) at 834px+
- Two-column Goals at 1024px+ landscape
- Two-column Payoff at 1024px+ landscape
- Centered modals and Settings sheet at 834px+
- Settings sheet max-width 600px on iPad
- All four iPad orientations supported

### Visual and interaction polish
- UI/UX polish pass: card depth, timeline spacing, goal card sizing, staggered entrance animations, premium hero shine, upgrade button gradient
- Bottom nav active state: glow effect in dark theme
- Page-specific headings per tab (Bills, Payoff, Goals)
- Section switcher icons, tab-switch fade animation
- Load More replaces numbered pagination across debts, goals, expenses, payoff order

### Quality fixes
- **Dark mode respects system preference on first launch** — `useDarkMode` now reads `prefers-color-scheme: dark` when no stored preference exists
- **Currency inputs fixed on iOS** — all amount fields changed from `type="number"` to `type="text" inputMode="decimal"` so the iOS decimal keypad appears (previously showed number pad with no decimal point, blocking cent entry). Affects: PaycheckSection, AddExpenseModal, GoalsSection (4 fields), LivingExpensesSection
- **Day-of-month fields** — changed to `inputMode="numeric"` (integer-only keypad)
- **Rollover pay cycle feedback** — "Start Next Pay Cycle" now triggers a medium haptic and a "Cycle complete — great work!" status message
- **Storage error logging** — corrupted localStorage entries now log a console.warn instead of failing silently
- **Living Expenses always visible on Bills tab** — was previously inside `bills-expenses-col`, hiding it when the Debts sub-tab was active; moved above the column layout so it's always shown. Also fixes the floating add button overlapping the "Manage" button header when scrolling
- Upgrade modal scrolls instead of clipping on short viewports
- Delete All Data (two-tap confirmation, Settings only, hidden during first-run setup)

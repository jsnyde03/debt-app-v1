# docs/archive

Historical, version-locked, and superseded documents. Nothing here is an active
plan — these are kept for reference only. Active planning docs live one level up
in [`docs/`](../README.md).

**What gets archived:** once a version is approved and live on the App Store, its
version-specific implementation doc and release notes move here. Superseded audits
(replaced by a living backlog) move here too.
